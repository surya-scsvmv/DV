# Dataset

`student_scores.csv` is the shared practice dataset used by the Python and R experiments.

| Column | Description |
|---|---|
| Student | Student name |
| Math, Science, English | Subject marks from 0 to 100 |
| Age | Student age in years |
| Hours_Studied | Study hours per day |

The records are fictional and are intended only for demonstrating data preparation, summary statistics, and visualization techniques.
